## Tasks Completed

### Base Task

Implementation of the provided neural network architecture for the Fashion-MNIST dataset using PyTorch.

Features:

* Custom neural network implementation
* Forward and backward propagation
* Training and validation pipeline
* Accuracy and loss tracking
* Visualization using Matplotlib
* Model weight saving using Pickle
* Test prediction generation (`submission.csv`)

---

### Applied ML Domain Task

Implementation of a Retrieval-Augmented Generation (RAG) based chatbot.

Features:

* Document ingestion
* Text chunking
* Vector embedding generation
* Similarity-based retrieval
* Context-aware response generation
* Conversational interface
